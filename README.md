# Hoppo 🐸

لعبة قفز (platformer) فالمتصفح: 5 عوالم، بوسات، مراحل سرية، لعب جماعي حتى 4 لاعبين، سباق، بلا نهاية، حانوت، إنجازات وصانع المراحل.

🎮 العب هنا: https://medo01012001.github.io/hoppo/

**التحكم:** الأسهم / WASD للحركة • Space / A للقفز • Shift / X للداش • ⬇ فالهوا للضربة للتحت • Esc / Start للتوقيف
